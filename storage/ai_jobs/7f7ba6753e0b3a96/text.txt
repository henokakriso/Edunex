Executive Summary

Modern security environments face an escalating volume of threats that traditional surveillance
systems and manual monitoring can no longer contain. The demand for instantaneous
situational awareness, reduced human error, and automated response has never been higher.
Buli Eyes is an AI-powered surveillance and intelligent monitoring platform engineered to meet
these demands. It transforms conventional CCTV infrastructure into a proactive, real-time
security intelligence network capable of facial recognition, weapon detection, license plate
recognition, and comprehensive personnel management—all without reliance on cloud
connectivity.
By deploying deep learning models locally on Linux-based servers, Buli Eyes delivers sub-second
threat identification, automates attendance and guard patrol verification, and centralises
monitoring across multiple camera feeds. The result is a dramatic improvement in operational
efficiency, a reduction in security personnel fatigue, and a hardened security posture suitable for
defence, government, critical infrastructure, and smart city applications.

System Overview

Buli Eyes is a modular, locally deployed AI surveillance platform that connects to existing IP
cameras or new installations. Video streams are continuously ingested by a dedicated Linux
server running a C-based processing engine integrated with OpenCV and the YOLO real-time
object detection framework. The AI engine simultaneously performs face detection, weapon
classification, and license plate recognition. All results are indexed and stored in a MySQL
database and surfaced through a web-based dashboard built with HTML, CSS, and PHP.



Key architectural principles include:


   Real-time monitoring with minimal latency (< 500 ms per frame analysis).
   Centralised dashboard for live viewing, event search, and reporting.
   Offline/local deployment to eliminate cloud dependency and reduce attack surface.
   Alert mechanisms including on-screen alerts, email, SMS, and API-based integration.
   Multi-camera management supporting simultaneous processing of 20+ channels on a single
   server.




Core Features
1. Facial Recognition

High-accuracy face detection and matching against enrolled databases. The system handles
pose variations, partial occlusion, and differing illumination, maintaining an identification rate
above 99% under controlled conditions.



2. Real-Time Face Identification

Live streams are matched against employee, VIP, and watchlist databases. Alerts are generated
immediately for unknown individuals in restricted zones or persons flagged as security risks.



3. Weapon Detection

Using the YOLO object detection model trained on extensive weapon datasets, the system
identifies handguns, rifles, knives, and blunt objects. Detection triggers instant lockdown
protocols and notification to on-duty operators.



4. Vehicle Plate Recognition

Optical character recognition extracts license plate numbers from video frames. Plates are
logged with timestamps, camera location, and vehicle thumbnails, enabling automated barrier
control and forensic search.



5. Attendance Tracking

Employees clock in and out through facial recognition without physical contact. The system
prevents proxy attendance by requiring liveness detection and matching live facial features
against the stored profile.



6. Employee Verification

Integration with HR databases ensures that only currently authorised personnel are granted
access. Revoked or expired credentials trigger immediate denial and alert.
7. Guard Assignment Validation

Security personnel are verified at post checkpoints using facial recognition. If a guard is absent
or an unauthorised individual attempts to log in, supervisors are notified in real time.



8. Patrol Checkpoint Timestamp System

Designated patrol checkpoints are equipped with NFC tags or QR codes. Guards scan using a
mobile device, and the system verifies identity via facial recognition, logging exact timestamps
and geolocation.



9. Watchlist Alerts

A dynamic watchlist module allows importing of person-of-interest records. Whenever a match
occurs on any camera, immediate alerts are sent with location and time.



10. Suspicious Activity Detection

AI analyses motion patterns, loitering, crowd density anomalies, and object left behind. Operators
receive early warning before situations escalate.



11. Audit Logs

Every system interaction—alerts, access attempts, configuration changes—is recorded in an
immutable, timestamped audit trail for compliance and investigation.



12. Multi-Camera Tracking

The system correlates detections across overlapping camera views to track individuals or
vehicles throughout a facility, providing continuous movement history.



13. Role-Based Access Management
Granular user roles ensure that operators, supervisors, and auditors see only the data and
controls relevant to their responsibilities.



14. Offline Secure Deployment

All components operate within the local network. No internet connection is required, ensuring
functionality during network outages and protection against remote cyber threats.

The AI pipeline operates as follows:


1. Capture – IP camera streams ingested via RTSP.
2. Preprocessing – Frame resizing, noise reduction, and format conversion using OpenCV
   functions called from C.
3. Inference – YOLO model loaded in memory performs object detection; separate face
   recognition models run on detected face regions.
4. Postprocessing – Non-max suppression, tracking ID assignment, and event generation.
5. Storage – Results pushed to MySQL through a lightweight PHP API.
6. Alerting – PHP scripts evaluate rules and trigger notifications.


Deployment infrastructure consists of one or more Linux servers, a Power-over-Ethernet switch,
and compatible IP cameras. No proprietary hardware is required.




Security Architecture

The system incorporates a defence-in-depth strategy to protect data, model integrity, and
operational continuity.


   Encrypted Storage – All sensitive data at rest (biometric templates, watchlists, audit logs) is
   encrypted using AES-256.
   Access Control – Role-based permissions enforced at the application and database levels;
   multi-factor authentication supported.
   Authentication – Strong password policies, session management, and optional integration
   with LDAP/Active Directory.
   Local Server Security – Linux server hardened with minimal packages, firewall rules
   (iptables), SELinux/AppArmor enabled, and disabled unused services.
   Audit Logging – Immutable logs record all authentication attempts, configuration changes,
   and data access, stored locally and optionally mirrored to a syslog server.
   Intrusion Prevention – Fail2ban monitors login attempts; network intrusion detection
   systems (e.g., Snort) can be layered in high-security environments.
   Secure Communication – TLS 1.3 for web console access; camera streams isolated on a
   separate VLAN with no default gateway.


Biometric templates are stored as irreversible mathematical vectors, not original images,
ensuring privacy compliance.
